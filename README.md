Still 是一个为电视设计的 Android 桌面：打开电视后，看到的是自己的应用、网页快捷方式与喜欢的壁纸。应用自动排列在首页，可以用遥控器搜索、整理和打开；没有内容推荐流、广告 SDK 或统计服务。

当前版本为 **0.9.19 预览版**，支持 Android 6.0（API 23）及以上系统。桌面替换、开机启动和待机唤醒能否生效，取决于设备与厂商系统，需在实际电视上验证。

## 功能

### 应用与搜索

- **应用墙**：自动展示设备上可启动的电视和普通应用；新安装的应用追加到末尾，卸载后自动移除。
- **遥控器交互**：上下左右选择，确定打开，长按打开菜单。选中卡片会放大并显示名称；设置中可选择始终显示名称。
- **整理应用**：长按菜单支持移动位置、移到最前或最后、重命名、查看应用信息和卸载。自定义名称只影响 Still；卸载需要系统确认，系统应用不提供直接卸载。
- **本地搜索**：支持名称、拼音、首字母和部分应用的常用别名。匹配准确度优先，同档参考使用频次；搜索不上传输入或使用记录。
- **焦点与恢复**：返回首页时尽量保留位置与焦点；向下浏览后按返回可回到第一行。应用列表和图标使用缓存，后台核对变化。

### 壁纸与屏保

- **外观与壁纸**：内置 7 款风景壁纸及经典浅色、深色；新安装默认使用 Sonoma（晨曦）。在「设置 → 外观与壁纸」使用遥控器左右键切换并保存。
- **桌面屏保**：在首页闲置后隐藏应用和控件，展示当前壁纸。默认等待 1 分钟，也可在「设置 → 桌面屏保」选择 30 秒、2 分钟或关闭。按键退出时恢复此前的焦点和位置。
- **亮屏时间**：进入屏保后，Still 最多保持亮屏 15 分钟，之后释放亮屏请求，由电视系统决定何时休眠；实际行为因设备而异。
- **环境光与状态**：焦点附近的柔和光影随应用变化；首页顶部显示时间、日期、网络状态、搜索和设置入口。

### 网页快捷方式

在首页选择「添加网页」，可以用遥控器填写，也可以通过同一局域网内的手机扫码填写名称和网址。网页会以快捷卡片出现在首页，长按可编辑或删除；打开时使用独立的浏览进程。

Still 会尝试获取网页标题和图标。网页本身的显示、登录和遥控器操作体验取决于网站及电视的 WebView 版本。

### 隔空安装

首页选择「隔空安装」，用同一局域网内的手机扫码或在电脑浏览器打开电视显示的地址，选择 APK 上传。上传完成后可查看安装包信息，并进入系统安装确认。传输服务在打开功能时启动，关闭窗口时停止；安装仍需用户在电视上确认。

### 桌面与更新

- **默认桌面**：设置中可查看当前桌面状态，并尝试打开系统桌面设置；也可临时打开电视原生桌面。
- **自动进入 Still**：一个开关控制开机和支持的系统上的待机唤醒。系统重启、短暂待机和长时间待机应分别验证，部分厂商可能限制第三方桌面。
- **手动检查更新**：设置中可检查、下载新版本，校验安装包后进入系统安装确认；不进行后台静默更新。

## 下载安装

[下载 Still 0.9.19 预览 APK](website/downloads/Still-0.9.19.apk) · [SHA-256 校验和](website/downloads/SHA256SUMS.txt) · [安装与电视验证说明](docs/安装与电视验证.md)

可以通过电视支持的 U 盘安装入口安装，也可以在开启 ADB 调试并授权连接后安装：

```sh
adb connect <电视地址和端口>
adb install --no-incremental -r app/build/outputs/apk/debug/app-debug.apk
```

上述命令使用本地构建的 APK；如使用下载的预览包，请将路径换成下载文件的路径。部分设备使用无线配对或动态端口，以电视显示的信息为准。

同包名、同签名的覆盖安装通常会保留 Still 的排序与设置。当前公开预览包使用开发调试签名；不同签名的安装包不能直接覆盖安装。卸载应用会删除其本地数据。

## 隐私与联网

Still 不包含广告 SDK 或统计服务。应用列表、排序、自定义名称、搜索使用记录、网页快捷方式和设置保存在本机。

网页浏览、获取网页标题和图标、手动检查及下载更新需要网络；添加网页和隔空安装会在使用时启动局域网服务。实际访问的网站及其内容由相应服务提供方处理。Still 不提供视频、直播源、音乐或其他第三方内容。

## 开发

| 项目 | 配置 |
| --- | --- |
| 语言 / UI | Java 17 / 原生 Android Views |
| 最低系统 | Android 6.0，API 23 |
| compileSdk / targetSdk | 35 / 35 |
| Android Gradle Plugin | 8.7.3 |
| Gradle Wrapper | 8.10.2 |
| JDK | 17 或 21 |
| 包名 | `com.jianping.tv` |

包名沿用早期版本，以支持同签名覆盖升级。应用不包含原生二进制依赖，不限定 ARM 32/64 位架构。

克隆仓库并安装 Android SDK Platform 35、Build Tools 35.0.0 后，在项目根目录的 `local.properties` 配置本机 SDK 路径：

```properties
sdk.dir=/absolute/path/to/Android/sdk
```

也可以通过 Android Studio 配置 SDK。`local.properties` 和本机签名密钥不提交到仓库。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Windows 使用 `gradlew.bat`。构建产物为 `app/build/outputs/apk/debug/app-debug.apk`。项目包含应用排序、更新、网页快捷方式、隔空安装、壁纸及屏保等自动测试；自动测试不能替代电视实机验证。
