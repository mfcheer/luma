如何安装到电视 ＋
  1. 下载 APK，复制到 U 盘，使用电视支持的安装入口打开。
  2. 按电视提示允许安装，完成后打开 Still。
  3. 后续使用同一签名的安装包覆盖更新，即可保留排序和设置。

也可通过已授权的 ADB 连接安装。默认桌面、开机启动和待机恢复取决于电视固件，需要分别验证。本预览包使用开发调试签名。

Still 是视频播放器吗？＋

Still 是电视桌面，用来展示和打开已安装的应用。它不提供影视内容、直播源或第三方会员服务。

安装后会自动成为默认桌面吗？＋

取决于电视系统是否允许。可在 Still 的“默认桌面”设置中查看状态并打开系统选择入口。Home 键、重新开机和待机唤醒应分别测试；安装成功本身不代表这三项已经生效。

画面里的应用会随安装包一起提供吗？＋

不会。所有截图与视频均取自真实电视，图标来自该设备已安装的应用，其标识属于各自权利人。Still 不包含这些第三方应用。

能在其他 Android 电视上使用吗？＋

最低支持 Android 6.0 / API 23，不依赖 ARM 32 位或 64 位原生库。当前重点验证设备为小米电视 5 Pro / Android 9，另有 Android TV API 33 模拟器回归。其他型号的系统入口、遥控器和开机行为需自行验证。
