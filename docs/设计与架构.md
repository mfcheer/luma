# Still 0.9.2 设计与架构

目标：小米电视5 Pro 55英寸，用户确认Android9/API28、MiTV OS2.17.3226。已在Android TV API33模拟器完成双主题回归，并在这台Android9电视安装、使用和采集新版画面；完整验证范围见qa-092/README.md。

## 首页内容与顺序

首页直接展示全部可启动应用，无收藏、手动添加、移出首页或独立“全部应用”入口。后台服务等没有启动入口的系统组件不展示。同包优先电视入口，其次普通启动入口。

首次安装按应用名称排列；升级时把旧版 favorites 当作顺序前缀，补齐其余应用，写入独立 appOrder。旧键只用于一次迁移回退，不再决定应用是否可见。新安装追加到末尾；卸载后移除；已有应用保留手动位置。按包名匹配顺序，应用更新更换入口类名也能保留位置。替换安装的临时 PACKAGE_REMOVED 不提前删位置，等待安装完成事件刷新。

AppOrder.reconcile 是独立纯Java函数，清理失效/重复ID并追加新项，重复刷新结果稳定。Preferences只保存顺序、显示名称选项、开机选项和诊断记录。AppRepository只负责发现应用与创建启动Intent。界面变化不改变这些数据约定。

## 布局与动效

延续 continuous-home-reference.png 的五列连续应用墙，约两行完整内容和下方淡化/模糊续行；无品牌字标或顶部重复预览。卡片120×78逻辑像素，可用宽864，横向间隔约53，行距156。

选中尺度1.14；首页与搜索在1920×1080下统一让图面底边上移5px，搜索卡片更大也保持相同上浮距离。单次进入260ms、轻微落点；连续切换120ms无回弹，退出120ms。从当前状态接续，确定键轻压后释放，下方柔和阴影强调层次。整理中的卡片额外上浮3、尺度增加0.012，在名称槽显示“移动中”；空闲无动画循环。

GridWallView提供明确方向键路径、稳定卡片ID、重排让位和滚动位置恢复。顶部保留padding作为上浮余量，绘制裁剪始终固定在视口边缘。上下渐隐通过固定视口的DST_IN遮罩统一绘制；搜索输入时关闭边缘处理以适应输入法布局。顶部只淡化实际离开的行，从实际视口起点开始，按滚动位置与最近整行对齐点的距离连续收放，最大48逻辑像素；底部保持48逻辑像素渐隐。部分行最多62%混入128×83的轻模糊图（单次均值滤波），不显示位置条；卡片透明度再降低最多16%。部分行使用缓存的低分辨率模糊图，不依赖Android12 RenderEffect。

IconArtwork优先使用真实TV横幅，没有横幅时等比保留原标识，绘到统一横向底面；素材适配、主色采样和预制模糊在后台完成。背景使用局部低饱和度柔光，停留110ms后响应，颜色520ms、位置460ms平滑跟随；滚动/让位时更新已有动画目的地。背景缓存256px径向光遮罩，绘制时更新边界和颜色，不在逐帧路径生成位图或Shader。不会伪造第三方图标。

## 长按与调整顺序

首页AppActionMenuView提供“移动位置”“移到最前”和“应用信息”；搜索结果提供“移到最前”“在首页定位”“应用信息”，复用相同菜单组件。应用预览、标题、线性图标与332逻辑像素宽的圆角面板保持复用；删除重复副标题与分隔线，头部64高，展开320ms、收起180ms，焦点隔离，返回原卡片。菜单中始终显示应用名称。

移动创建独立顺序草稿；方向键插入目标位置，确定保存、返回或Home撤销。整理/菜单期间包变化先更新已安装数据和基础顺序，延后重建界面；移动及提交时再次归并最新可用应用，避免丢失新项或保存已卸载入口。外部应用返回保留焦点与滚动偏移。

设置的“始终显示应用名称”默认关闭，首页和搜索结果仅选中时显示居中名称；开启后所有卡片显示，已有显式偏好保留。90ms（快速140ms）后淡入，离开80ms淡出；固定名称槽保留卡片几何与无障碍名称。菜单保留来源名称，顶部/输入框隐藏卡片名称。开关和排序独立保存。桌面、应用、设备三组设置共七项，包含外观主题，保留焦点轻微浮起。

## 组件与兼容

- data/AppRepository、AppEntry：同包去重的启动入口与原始素材。
- data/AppOrder：应用列表与用户顺序的无状态归并。
- data/Preferences：顺序迁移、排序与选项持久化。
- ui/SearchActivity、data/AppSearch：独立查询/焦点/偏移、名称与拼音索引，复用目录缓存、卡片和菜单；通过显式结果在首页定位。
- ui/MainActivity：加载、页面/菜单生命周期、编辑事务与系统入口。
- ui/AppCardView、GridWallView：可复用卡片与五列连续应用墙。
- ui/AppActionMenuView、SettingsRowView：统一遥控器操作的菜单与设置行。
- ui/IconArtwork、IconPalette、AmbientBackgroundView：素材适配、主色与有限环境光过渡。
- platform/BootReceiver、DeviceDiagnostics：开机通知、启动请求、界面进入和默认桌面检测。

原生Java/Android Views，minSdk23，compile/target35，无原生二进制依赖。保留com.jianping.tv与原签名，覆盖升级继承顺序和设置。无联网权限、广告/统计SDK、悬浮窗或无障碍服务。

默认桌面入口区分API29，Android9使用ACTION_HOME_SETTINGS。开机通知、请求与真正进入分别记录，默认关闭开机实验。不禁用原厂桌面；Home、开机与待机接管仍需实机确认。历史设计和验证过程见验证记录及根目录design-qa.md。

## Still 品牌资源（0.7.1）

用户选择蓝色 S，替换原来的白色图案。drawable-nodpi/still_icon_v2.png 是512px源；mipmap各密度导出48/72/96/144/192px带透明圆角的旧系统图标；API26以上使用mipmap-anydpi-v26自适应图标和独立深色底，前景留12dp安全边距。无原生库或新增权限。

## 0.7.2 首页精修

时钟使用常规字重与等宽数字特性；首页设置入口改用Google Material圆润实心设置图标，与时钟统一重量。应用墙改为top82/height424、paddingTop16，卡片原位置和五列行距保持不变，顶部多出4逻辑像素的绘制余量，容纳整理状态的额外抬起。

GridWallView向宿主报告焦点中心（桌面坐标），首次布局、滚动和排序平移更新光源位置；正常导航使用有限动画，滚动和排序动画本身已平滑时同步跟随。AppCardView独立管理焦点、按压、边界预览和整理进度，取消旧过渡后从当前状态接续；离屏时释放动画监听。菜单与排序继续使用既有焦点隔离、草稿与确认协议。


首页和设置页的右上角共用两行时钟：时间18逻辑像素，日期/中文星期12逻辑像素，右对齐，日期格式yyyy年M月d日 EEEE。两行由同一个Date瞬时值格式化，随设备本地时区刷新；仅在文本变化时更新TextView，避免每秒对相同文本请求布局。整理提示框宽度缩为480逻辑像素，与日期框保持间隔。


## 0.8.0 浅色与深色主题

`UiPalette` 集中管理背景、文字、焦点、设置面板、菜单、遮罩与卡片名称等语义颜色；每次构建页面将同一配色传给各个原生 View。应用自身图标素材不随主题改色。`Preferences.appearance` 保存 `light`/`dark`，缺省或无效值回退浅色。主题选择位于桌面组第四行，原名称开关的导航次序保持不变。

浅色背景从近白 #FAF9F7 向 #F2F2F0 柔和过渡，焦点主色染色峰值约6%，比已确认的暖灰稿更白。未选中卡片共享一份小尺寸阴影纹理，焦点阴影与少量主色光单独缓存；不在逐帧绘制中分配位图。浅色下收淡原生 elevation 阴影，API28 起调整其颜色，较低版本使用更小的深度。日期、次级文字和名称使用灰蓝色以保证白底阅读。深色沿用低亮石墨底与原有光影。两种主题均使用现有有限动画，空闲时不持续重绘。

Activity 在 `super.onCreate` 前读取偏好并设置原生浅/深主题，使原生选择与设备报告对话框跟随外观。选择后更新主题并重建页面，不销毁 Activity，保留设置行焦点、首页选择与偏移；不修改应用顺序、名称或开机选项。七行设置收紧至42逻辑像素，连同分组标题可完整显示。


## 0.8.1 目录缓存与恢复

AppEntry 只保留组件、名称和包更新时间/版本/语言指纹；AppRepository 先查询轻量元数据，只有缓存失效的应用才按原640dpi加载图标/横幅，维持素材质量。AppCatalogCache 保存进程级不可变快照，并在缓存目录以 AtomicFile 保存版本化目录、384×250卡片、128×83预览与主色；偏好不放入缓存。以后改变素材生成算法时应提高 FORMAT，避免复用旧生成结果。

正常 onResume 复用页面，不再无条件扫描或重建图标。Activity 重建先使用进程快照；进程死亡后在后台读取磁盘快照并尽早呈现，再查询包元数据。未变化的目录不重建页面、不重绘图标；包广播合并触发刷新，只失效受影响包，应用更新保位、卸载移除、新增末尾规则保留。工作可中断，过期结果不发布；生成完成先显示界面，再写磁盘，缓存缺失或损坏回退重建。空加载墙不覆盖已保存的滚动偏移，列表读取异常会保留旧画面或提供可重试提示。

IconArtwork 保留精确的透明边界扫描，表面颜色分类改为稀疏采样；IconPalette 一次取出像素，避免逐像素JNI调用。ArgbBlur 使用滑动窗口，与原半径2的双向盒式模糊逐像素一致。

默认桌面先显示状态面板，系统设置跳转失败或没有可见页面时提供说明；可显式打开其他真实桌面，过滤系统 FallbackHome/Resolver/Chooser 入口。报告同时显示 Home 解析组件与候选，不能把 android 包的解析器当成默认桌面。用户已实测小米电视从其他应用按 Home 回 Still；开机和待机唤醒仍分别验证。

同版修复跨行闪动：旧实现仅在 `scrollY % rowHeight == 0` 时将顶部渐隐从全开切为零，同时将裁剪边界上移整个padding。新实现固定裁剪，并将渐隐长度连续限制为最近整行边界的距离；使用padding绘制偏移让渐隐覆盖顶部上浮余量，避免其上方留下一条未经淡化的图面。没有新增逐帧位图分配、全屏离屏图层或常驻动画。
