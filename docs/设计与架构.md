# Luma 0.4 设计与架构

目标设备：小米电视 5 Pro 55 英寸，MiTV OS 2.17.3226。Android 底层版本待实机读取。

## 视觉与交互

首页上方为严格水平居中的应用大图标，不重复显示名称和操作提示；名称保留在下方六列收藏网格。一屏两行，方向键跨行时按完整两行定位，避免残缺图标长期停在边界。透明渐隐只在滚动过渡中出现，停下后恢复清晰。

“全部应用”使用与应用相同的图标格子，排列在收藏末尾，取消全宽按钮、收藏数量标题和固定底部说明栏。大图标与选中项保留柔光及细边。

应用名改为 Luma，包名与存储键保持不变，兼容旧版覆盖升级。顶部为细字重品牌字标和等宽数字时间，设置/返回采用无框图标，仅焦点时轻微浮起。

设置为居中紧凑列表，左侧不再预留大标题列，五个主要操作同时可见。设备报告移到独立详情弹窗，保留复制操作，避免长说明挤占设置列表。功能与收藏存储保持不变。AppRepository 优先加载 xxxhdpi 图标资源，缺失时回退系统图标。

首次自动选取最多 5 个应用，之后由本地收藏列表控制。全部应用长按收藏，首页长按移除、前移或左右排序。不会自动轮播或自行移动焦点。

## 可复用模块

- data/AppEntry：稳定组件 ID、名称、真实图标。
- data/AppRepository：TV 入口优先，手机入口补充，按包去重；应用启动 Intent。
- data/Preferences：独立持久化收藏排序、开机实验开关、检测记录。
- platform/DeviceDiagnostics：系统版本、CPU ABI、默认桌面和启动记录。
- platform/BootReceiver：接收开机通知，实验性启动并记录；默认不开启。
- ui/MainActivity：原生 Android 视图、遥控器焦点与页面切换。
- ui/FocusHaloDrawable：兼容旧系统的缓存柔光，主页与网格共用。
- ui/FavoritesScrollView：按完整两行定位和过渡渐隐。
- ui/AmbientBackgroundView：围绕 hero 中心的原生径向光，620ms 有限颜色过渡，空闲时不循环绘制。
- ui/IconPalette：一次性采样图标的主色并缓存，排除透明和中性像素。

保留包名 com.jianping.tv、组件 ID 与存储键，后续直接升级同一应用。正式分发前需配置持久的发布签名；当前为测试签名，后续测试升级需保留同一调试密钥。建议随后按页面拆分 UI 类，增加主题和用户配置版本迁移，底层模块无需重写。

## 兼容策略

minSdk 23（Android 6），不含原生二进制，不限制 ARM 32/64 位。compileSdk / targetSdk 35；旧电视兼容由 minSdk 决定。新 Android 上开机后台拉起限制仍按平台规则处理。无联网、悬浮窗、无障碍服务、Root 权限，不修改或禁用系统桌面。

界面参考 960×540 逻辑坐标，随屏宽缩放，适配目标电视 16:9 横屏。不做网页替代品，交付原生 APK。

## 开机与 Home 验证边界

默认桌面由系统决定。ROLE_HOME（Android 10+）或系统桌面设置只发起用户选择，不绕过系统权限。Boot 通知、启动请求、界面实际进入分别记录，后台启动可能静默失败。待机恢复和冷启动单独检查。不模拟或伪造已在小米设备通过。

## 0.4 光影与品牌

旧右上角壁纸归档至 assets/wallpaper-v1.png，不再打入 APK。新背景为代码原生绘制，主要光源对齐 960×540 坐标中的 (480,152)，随选中应用的主色在 620ms 内过渡。更换焦点时取消上一次过渡，从当前颜色继续，不循环呼吸闪动。大图标边缘光与环境光使用同一主色。

图标色采样为 32×32，按饱和度与亮度加权；近白/灰应用回退冷蓝。不同 ImageView 使用独立 Drawable 实例，避免大图与网格互相修改 bounds。原有设置行的浅色选中和 1.025 倍浮起保持不变。

Luma 图标由 ImageGen 创建，原始素材 docs/luma-icon-original.png，Android 使用缩放的 luma_mark.png。
