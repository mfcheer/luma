# Still 0.9.3 自动进入回归

final result: passed

## 行为与界面

设置保留原有分组、行高和开关样式，将“开机启动”改为同一个“自动进入 Still”开关。沿用已有偏好，开机和待机唤醒一起开启/关闭；没有增加第二个配置步骤。Android6–9支持新的事件监听，较新系统明确显示“仅开机”，不启动尚未适配的唤醒服务。

亮屏后约1秒请求回到Still首页，每个熄屏/亮屏周期只执行一次。搜索、菜单和排序草稿退出，已保存的应用顺序保持。服务在系统恢复后只重新监听，不抢当前应用；只有下一次真实唤醒才返回首页。关闭开关会停止服务和通知。

实机从首页、独立日历应用、小米原生桌面及搜索页唤醒均回到Still首页；前三项逐次核对只有一个请求，匹配对应 `onResume` 进入记录，随后继续检查前台稳定。测试期间没有在验证唤醒的路径中手动启动Still来代替服务行为。应用顺序、外观、名称、开关及默认桌面保持，结束息屏。未安装测试应用到电视。
