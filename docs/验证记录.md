## Android 9.0 目标确认

用户确认目标电视为 Android 9.0（API 28），并非通过 ADB 读取。当前 minSdk 23，未发现仅支持新版系统且未防护的接口调用；默认桌面的 RoleManager 路径有 API 29 版本判断，API 28 使用 ACTION_HOME_SETTINGS。注册广播的新接口有 API 33 分支。当前不因版本确认而修改 SDK 或重新发布 APK。

这次为代码检查，未新增 Android 9 运行测试。既有模拟器是 API 33；Android 9 真机的安装、焦点/动画、应用发现、默认桌面、重启和待机恢复仍需验证。尤其系统设置入口和开机启动结果依赖小米固件，不能用 API 级别推断成功。
