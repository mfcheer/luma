在该模拟器执行 set-home-activity 返回 Success，但 resolve-activity 与 Home 按键仍指向 com.google.android.tvlauncher/.MainActivity。说明命令成功不能当作最终行为成功。没有禁用或卸载模拟器的原厂桌面。
