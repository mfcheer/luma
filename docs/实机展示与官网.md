# Still 实机展示与官网（2026-10-22）

## 设备与安装

通过用户开启并授权的局域网 ADB 连接，确认设备为小米电视5 Pro 55英寸 / MiTV-ANSP0，Android9 / API28，系统UI渲染1920×1080、density320。0.8.1（versionCode15）已使用同签名覆盖安装，升级前后核对应用顺序、名称、主题和开机选项保留。当前设备有41个可启动应用，系统解析的默认Home组件为 `com.jianping.tv/.ui.MainActivity`，与用户实测从其他应用按Home回Still相符。

这是安装、UI展示与采集记录，不替代断电开机、系统重启、长期待机恢复或受控性能基准。没有在真实电视安装模拟器测试应用，也没有将模拟器的偏好种子写入真实电视。

## 媒体来源

所有官网主展示素材均直接采自电视上运行的Still 0.8.1：

| 素材 | 内容 |
| --- | --- |
| `website/assets/home-light.webp`、`home-dark.webp` | 真实应用的浅色和深色首页 |
| `scrolled-light.webp`、`scrolled-dark.webp` | 多应用墙上下滚动后的续行 |
| `menu-light.webp`、`moving-light.webp` | 长按菜单、跨行移动草稿，最终撤销 |
| `settings-light.webp`、`settings-dark.webp` | 两种主题的原生分组设置 |
| `still-tv-preview.gif` | 浅色焦点切换和上下滚动，768px宽，适合README内联展示 |
| `still-tv-demo.mp4` | 三段原生录屏按原速拼接，H.264 / 1920×1080，无音轨，约76秒；媒体信息见`media.json` |

图片经过WebP编码；网页局部展示使用CSS裁切，未重画应用图标或替换界面。视频不插帧、不加速。原生录制链路是可变帧率，平均编码帧率不能用来判断电视面板刷新率或真实操作流畅度。录像未打开第三方应用内容页、账号信息、设备诊断或网络设置。

Android9的ADB `input --longpress`与实物遥控器长按的行为不同，采集工具使用同一张应用卡片上的静止长按手势打开同一个菜单，然后通过方向键恢复焦点。此前采集脚本对待机、触摸模式焦点和已记忆的设置行有错误假设，已改为检查电源状态、退出触摸模式和按当前行定位。它们是采集工具兼容问题，没有为录制改动或重新安装应用。

实机采集脚本为 `scripts/capture-tv-081.py --serial <电视地址:端口>`，支持`--phase menu`和`--phase dark`分段采集。不会安装测试应用或替换偏好文件；移动草稿撤销、通过UI还原原外观，核对原应用顺序、名称与开机选项。原始PNG、MP4、UI树和偏好备份留在忽略的`output/real-tv-presentation/`，不公开家庭环境照片、IP、MAC或偏好文件。

## 官网实现

`website/` 是独立的无构建静态站：原生HTML/CSS/JavaScript、系统字体，无框架、统计或第三方字体请求。延续Still的珍珠白、蓝色S、舒展留白和轻柔反馈，提供真实主题预览、原生视频控件、安装说明、FAQ、APK与校验和下载。移动端修复了装饰光晕造成的1px横向溢出；手机正文与问答字号提高，主题按钮、键盘焦点、跳转主内容和减少动态效果偏好有明确处理。

本地以 `python3 -m http.server 4173 --directory website` 运行。浏览器检查390×844手机布局及桌面布局；验证浅深图片切换、视频元数据/播放、说明和FAQ展开、页面资源和锚点存在。下载APK的SHA-256与电视已安装的0.8.1包一致：

`d81908aabd0530302cb8bce50efbc6ff87fccb959d189b05b4240af0fd93dd55`

`.github/workflows/pages.yml` 仅部署`website/`。公开仓库推送自动执行，私有仓库默认跳过，避免在不支持Pages的套餐中制造失败；支持私有Pages的套餐可设置仓库变量`STILL_PAGES_ENABLED=true`或手动运行。实际发布前仍需在仓库Settings → Pages选择GitHub Actions。

当前仓库的Pages设置页面明确提示需要升级套餐或改为公开。可以选择保留应用仓库私有、另建只包含官网的公开仓库；也可以在明确同意后公开原仓库，或升级支持私有Pages的套餐。套餐能力参考[GitHub Pages官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。
