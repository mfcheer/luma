## 搜索结果长按

复用已有 AppActionMenuView，提供“移到最前”“在首页定位”“应用信息”。取消只关闭菜单，回到同一查询、应用和偏移；菜单隔离背景焦点。置前保留其他应用顺序和原查询，重新应用同等匹配的首页顺序；重复置前为无操作。定位退出搜索，在首页聚焦目标并滚到可见区域。

首页通过Activity结果接收明确的目标，普通搜索返回仍保留原首页位置。搜索保存待同步的目标，实际进程死亡后恢复也能完成首页同步。共享的 AppOrder.moveToFront 不修改输入顺序，也不丢弃搜索打开期间新出现的应用。

- `search-menu-091-smoke.py`：API33 / ARM64 / 1920×1080，24个测试应用加4个系统入口；浅深主题通过取消菜单精确恢复焦点/滚动、焦点隔离、定位不排序、置前保序、重复置前、应用信息、真实进程死亡、应用启动返回及首页同步，见 `search-menu-smoke.json`。原偏好完整还原。
- 复用 `search-090-smoke.py`，指定 `STILL_EXPECT_VERSION=0.9.1`、`STILL_QA_OUT=docs/qa-091/search-regression`：双主题通过拼音/英文、实时输入不抢焦点、键盘Back分层、多行、清空、无结果、原首页位置及真实进程死亡恢复。
- `AppOrderTest.java`：迁移/增删/组件变更等既有顺序规则，以及置前保持原输入、其他应用、重复执行与不存在目标，见 `order-test.txt`。

首次菜单测试曾直接在应用信息页后执行 am kill。TV设置为半透明页面，Still依然可见，系统不会回收它；该次脚本失败不计为通过。修正为用不透明测试应用遮挡后，确认PID实际消失，再依次返回应用信息与搜索，完成两种主题的恢复验证。未为测试修改产品行为。
