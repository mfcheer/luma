# 安装与电视验证

## 首次安装

将 output/Luma-0.4.0-debug.apk 复制到 U 盘，通过电视文件管理器安装。若系统拦截，查看电视的安装未知来源应用设置。安装后在应用列表打开“Luma”。U 盘安装入口因小米固件可能不同，无法保证支持。

也可通过电视开发者选项启用 ADB 调试，在同一局域网电脑运行以下命令（替换 IP）：

```sh
adb connect 电视IP:5555
adb install -r output/Luma-0.4.0-debug.apk
adb shell am start -n com.jianping.tv/.ui.MainActivity
```

只连接你自己的电视，并在电视确认调试授权。若无线调试使用动态端口/配对码，按电视显示的端口执行 adb pair / adb connect，不假定所有固件都使用 5555。

## 逐步验证

1. 打开简屏，确认应用列表、上下左右焦点和确定启动正常。
2. 全部应用长按收藏；首页长按移动和移除。关闭再打开确认保存。
3. 设置中拍下设备报告，确认 Android 版本/API、架构和当前默认桌面。
4. 点击“设置默认桌面”，如系统弹出选择器，选择简屏。按 Home 验证是否返回。
5. 设置开启“开机启动实验”，通过电视正常重启。记录是否进入简屏；查看开机通知/请求/界面实际进入的时间。
6. 分别测试遥控器待机唤醒、系统重启、断电后再开机。结果分开记录。

系统未提供桌面选择器时，先只读检查：

```sh
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.sdk
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell dumpsys package com.jianping.tv
```

支持 set-home-activity 的固件，可先记下上述默认桌面的完整组件，再尝试：

```sh
adb shell cmd package set-home-activity com.jianping.tv/.ui.MainActivity
```

旧系统可能无此命令或拒绝操作。失败时保留输出进一步判断，不禁用原厂桌面。
恢复：在系统默认桌面选择中切回小米桌面，或使用同一命令设置为此前记录的完整组件。找不到切换入口时可经 ADB 卸载简屏，原厂桌面仍保留：

```sh
adb uninstall com.jianping.tv
```

卸载会删除简屏的收藏和检测记录。开机广告及视频 APP 内广告不属于桌面应用可控制范围。
