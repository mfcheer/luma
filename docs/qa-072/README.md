# 0.7.2 首页精修验证

目标：用户确认审查中的五项建议，第5项明确不加位置条。保留五列、两行半和原有间距。

## 变更

- 时钟从轻字重调整为常规字重、等宽数字；首页设置入口采用Material圆润实心图标。
- 背景主色460ms过渡，光源位置380ms跟随；滚动与排序平移同步更新位置。缓存光遮罩，无空闲循环。
- 普通聚焦340ms进入，200ms以内的连续导航使用150ms响应，160ms退出；保留1.20倍/上浮10的目标，收敛细边与下方光池。
- 长按面板332宽、22圆角，去掉重复副标题与分隔线，头部从76收至64。
- 整理卡片额外上浮3、放大0.012，配合更清楚的细边与“移动中”；结束后恢复名称开关的原状态。
- 边界48逻辑像素渐隐；128×83轻模糊缓存，混入最多62%，保留轮廓。没有位置条。

## 环境与回归方法

Android TV API33 ARM64，1920×1080，2048MB内存。初期SwiftShader软件渲染出现约800ms的帧中位数和UIAutomation空根节点，固定延时的排序/焦点检查失败；改为本机Apple M1硬件渲染，脚本改为检查新鲜UI树、等待实际首页和异步写入结果。此后在最终APK上完整功能回归通过。模拟器的渲染数据不用于断言小米电视流畅度。

启动前模拟器有一次蓝牙服务自身崩溃，保存在emulator-startup-crash.txt；与Still无关。后续最终回归单独检查应用及系统崩溃缓冲区。

- all-apps-smoke.txt：最终APK的全量功能回归日志；截图在regression/，不覆盖历史0.7.0证据。
- scripts/home-polish-072.py：快速反向/稳定画面、空间光源跟随、菜单、整理标识、滚动、名称选项及实际录像。
- 后续视觉证据与最终检查结果将在本文件下方记录。

## 最终结果

- assembleDebug / lintDebug通过：0错误、15警告；新增一项官方圆润设置图标的长Vector路径提示，其余沿用原警告。AppOrderTest通过，包名及签名保持一致，versionCode13 / versionName0.7.2。
- all-apps-070-smoke.py在最终APK上完整通过：28应用、迁移、排序保存/撤销/重启、真实包增删替换、整理期间包变化、外部应用/系统信息返回、名称与开机设置保留。
- home-polish-072.py通过：24次快速反向后焦点/bounds正确，静止两次画面像素一致；两项精简菜单与焦点隔离、入场中返回；唯一“移动中”标识、跨行整理和草稿撤销；首尾行截图、名称恢复、设置与顺序保留。结束恢复模拟器原偏好。
- 光源独立复核：相同颜色的测试应用从第二行左侧移动到右侧，截取避开卡片与局部阴影的y134–160顶部空白条，43467像素发生变化；证据light-left.png / light-right.png / light-position.json，确认光源跟随位置而非只变色。
- 已打开comparison.jpg并排对比旧版和新版同一应用/状态；新版保留原卡片位置与间距，底部轮廓更清楚，菜单更紧凑，编辑状态有明确标识。实际检查首页、菜单、整理首行/跨行、滚动/末尾、名称开启与设置均无非预期裁切；不显示位置条。
