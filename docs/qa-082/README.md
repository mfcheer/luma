# Still 0.8.2 首页返回首行（2026-10-22）

版本 Code 16，包名、最低 API 23、签名和权限保持不变。本版只增加首页返回快捷操作，复用应用墙已有焦点和滚动逻辑，不重新创建首页或读取应用目录。

## 操作规则

- 首页焦点在第二行或更下面：按返回，滚回顶部并选中第一个应用。
- 已在第一行：保留当前选中的应用，继续留在首页。
- 长按菜单打开时：返回只关闭菜单；整理时返回只撤销本次移动；设置页返回只回到首页。这些行为仍先于返回首行处理。
- 从其他应用按返回：先恢复之前的首页焦点与滚动位置；再次在首页按返回才回首行。Home 键行为不变。
- 读取中或没有应用时：返回安全留在首页。

## 验证方法

`scripts/back-home-082-smoke.py` 在专用 Android TV API 33 / ARM64 / 1920×1080 模拟器执行，28 个可启动应用中有 24 个测试应用。使用真实 ADB 方向键、返回键和长按确定事件，不直接调用新增方法。

两种主题分别检查：首行第四列选中状态保留、第二行和最后一行返回到首个应用的准确边界、快速向下/返回及连续返回、菜单关闭后再返回、跨行移动撤销后再返回、外部应用退出后再返回、设置返回后保留首页选择。返回后再次等待，确认旧滚动动画不会把页面拉回下面。结束恢复完整原偏好，应用顺序、名称开关与开机开关不变。

结果见 [back-smoke.json](back-smoke.json)。`light-before/after.png` 和 `dark-before/after.png` 为模拟器深行和返回后的截图，仅作测试证据，未替换官网的小米实机素材。

构建命令 `./gradlew :app:assembleDebug :app:lintDebug` 通过，Lint 0 错误、16 项既有警告，见 [build.txt](build.txt)。[APK 信息](apk-badging.txt) 确认 0.8.2 / Code 16 / minSdk 23；[签名](apk-signature.txt) 与 0.8.1 相同，可覆盖升级。
