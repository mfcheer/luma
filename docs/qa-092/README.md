# Still 0.9.2 焦点名称与导航打磨

当前预览版，versionCode20，minSdk23 / targetSdk35。官网提供同签名0.9.2下载，并更新为这台电视上的新版截图、视频和动图。

最终结果：通过。浅深主题下首页与搜索底边均精确上移5px；搜索独立回归与真实进程死亡恢复通过，完整偏好还原。选中宽度274px，相对240px普通卡片约1.142倍。构建及Lint通过（0错误，17项既有警告）。

## 行为

- 首页、搜索结果共用 AppCardView：默认仅选中显示名称，居中、单行、省略超长名称。名称槽始终占位，不改变行距；离开后80ms淡出，停留90ms（快速导航140ms）后120ms淡入。长按菜单保留来源应用名称；回到搜索框或首页顶部后隐藏。
- 设置改为“始终显示应用名称”：开启显示全部，关闭仅选中显示。缺少偏好时默认关闭；已有显式偏好和应用顺序保留。
- 选中放大1.14倍；按用户最终选择，保留此前首页的轻微浮起：首页与搜索选中卡片的底边均上移约5px（1920×1080基准），以主界面比例计算上浮距离，不随搜索卡片的1.2倍尺寸增加。单次260ms克制落点，快速120ms无回弹；确定键按压反馈保留。柔和下投影替代环绕彩光，降低边缘高光。
- 上下边缘共用固定视口的透明渐变。上方只淡化实际离开的行，完整顶行不泛白；保护选中项与名称。搜索输入时关闭渐隐与模糊，避免与输入法布局叠加；移除搜索布局对Android原生渐隐的重复开启。
- 局部环境光降低饱和度、缩小范围，停留110ms后才响应；颜色520ms、位置460ms跟进。滚动更新已有动画的目的地，空闲无持续渲染循环。
- 滚动以卡片和名称可见范围为约束，兼容搜索页较大卡片、输入法改变视口高度及返回时的偏移恢复。

## 视觉依据

用户提供的Apple TV参考照片用于确定焦点名称与层次。`../designs/focus-092/home-concept.png`为ImageGen概念图，实际界面继续使用已有应用素材和五列布局；不把概念图作为运行截图。

本目录PNG/XML是API33 ARM64、1920×1080专用模拟器的实际输出，24个明确命名的测试应用和4个系统入口。测试应用的重复九宫格图标来自测试APK，不是Still替换真实应用图标；测试素材未用于官网或电视。

## 回归

最终结果以 `focus-smoke.json`、`search-regression/search-smoke.json` 和 `record-run.txt` 为准。

- `scripts/focus-092-smoke.py`：两种主题，缺省/显式名称偏好、名称居中且不改变行距、顶部/输入框隐藏名称、快速往返与空闲静止、全部六行、两个菜单取消、搜索启动返回、名称开关及重启。分别采样首页和搜索的测试卡片像素底边，验证均上移5px，允许最多1px栅格误差；搜索名称的边界按实际动态视口校验。
- `scripts/search-090-smoke.py`：通过版本与输出目录参数复用搜索回归，检查拼音/英文匹配、实时输入不抢焦点、键盘返回分层、多行、无结果、清空，以及实际进程死亡后的查询/焦点/偏移恢复。
- `scripts/record-focus-092.py`：采样选中图标宽度，并录制模拟器切换、快速往返、上下滚动、搜索及菜单；结束后恢复完整偏好。screenrecord捕获上限40秒，稳定回到首页后正常停止；最终编码流约19.07秒、1920×1080 H.264，未加速剪辑；不能据此推断电视刷新率。视频见 `focus-navigation.mp4`，抽帧见 `motion-contact.jpg` / `scroll-frames.jpg`，元信息见 `recording-media.json`。结尾稳定首页已单独检查。

中间运行曾修正测试应用本身没有焦点节点的断言，以及搜索视口固定991px的错误假设；搜索实际高度由输入法和窗口动态决定。中断的旧包运行及这些失败不计为最终通过。迭代诊断保存在忽略的output目录。
